# VantyX – Markets move fast

Dein Trading-Cockpit für Journal, Statistik, Marktdaten und TradingView (Windows).

## Installieren
1. **[VantyX-Setup.zip herunterladen](https://github.com/Zesora97/vantyx-releases/raw/main/setup/VantyX-Setup.zip)**
2. Rechtsklick auf die Datei → **Alle extrahieren…** → **Extrahieren**
3. Im Ordner **VantyX Setup** doppelt auf **Setup.cmd** klicken → **Installieren**

## Updates
Laufen automatisch: VantyX prüft selbst, ob es eine neue Version gibt, und zeigt dann oben
**„Update … – jetzt neu starten“**. Einmal klicken, fertig.

Aktuelle Version: siehe `latest.json`.
