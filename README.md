# VantyX – Releases

Hier liegen die Versionen von **VantyX** (Markets move fast).

- **Neu installieren:** bei der neuesten Release `VantyX-Setup-…-Beta.zip` herunterladen, entpacken, `Setup.cmd` starten.
- **Updates:** passieren automatisch – VantyX prüft selbst, ob es hier eine neue Version gibt.
