# Nyxor – Trade with clarity

*(ehemals VantyX)*

Dein Trading-Cockpit für Journal, Statistik, Marktdaten und TradingView (Windows).

## Installieren
1. **[Nyxor-Setup.zip herunterladen](https://github.com/Zesora97/vantyx-releases/raw/main/setup/Nyxor-Setup.zip)**
2. Rechtsklick auf die Datei → **Alle extrahieren…** → **Extrahieren**
3. Im Ordner **Nyxor Setup** doppelt auf **Setup.cmd** klicken → **Installieren**

## Updates
Laufen automatisch: Nyxor prüft selbst, ob es eine neue Version gibt, und zeigt dann oben
**„Update … – jetzt neu starten“**. Einmal klicken, fertig.

Aktuelle Version: siehe `latest.json`.
